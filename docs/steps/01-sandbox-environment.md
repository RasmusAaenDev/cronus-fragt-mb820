# Step 01: Create a sandbox environment

Delivers a runbook, `docs/runbooks/create-sandbox.md`, for creating the `CRONUS-DEV` sandbox, with a table of values a person must note down and a draft message to Mette. The environment itself was **not** created: that needs admin access to a Business Central tenant, which this work does not have.

| Checklist item | Status |
|---|---|
| Sandbox exists and is Active | Not done. Runbook steps 1-6. |
| Can open and sign in to the web client | Not done. Runbook step 7. |
| Environment type and application version noted | Not done. Table has placeholders, no invented values. |
| Update window noted and shared with Mette | Not done. Runbook step 8 and the draft message. |

What remains for a person: run the runbook, fill in the table and send Mette the message. The name `CRONUS-DEV` is used by the launch configurations from step 02 on.
