# Step 1: Create a sandbox environment

Cronus Fragt · MB-820 workbook · Environment and tools

This page is the task description for the step. The code and documents on this branch are the model solution.

## What Mette says

> Hi! We're about to start on the freight solution, but I don't dare let anyone mess around in our real books.
> Can you set up a place where you can build and test in peace? And let me know when Microsoft is allowed to
> update it, so we don't get a surprise in the middle of a demo.

## Your task

In the Business Central admin center, create a sandbox environment for the Cronus Fragt project. Give it a name the team will recognise, choose the country/region Cronus works in, and wait until it is active. Then note the environment's type, its application version and its update window, and tell Mette when updates may run.

## Checklist

- [ ] A sandbox environment for the project exists in the admin center and its state is Active.
- [ ] You can open the sandbox in the web client and sign in.
- [ ] You have noted the environment type (Sandbox) and the application version it runs.
- [ ] You have noted the environment's update window and shared it with Mette.
